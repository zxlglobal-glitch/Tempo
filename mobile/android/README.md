# TEMPO Android (прототип)

Эта отдельная папка содержит оболочку Capacitor 8 для тестирования TEMPO на Android. **Ветка не изменяет рабочий сайт, Netlify и базу Supabase.**

## Требования для Windows

- Node.js 22+ (проверка: `node -v`)
- Android Studio c Android SDK, установленным через SDK Manager
- Реальный Android-телефон с отладкой по USB либо эмулятор Android

## Начало работы

Открой терминал в этой папке и выполни:

```powershell
npm install
npx cap add android
npx cap sync android
npx cap open android
```

После запуска Android Studio дождись Gradle Sync, выбери подключённый Android-телефон/эмулятор и нажми **Run ▶**. Для отладочного APK можно использовать **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

**Важно:** текущий прототип открывает существующий HTTPS-сайт TEMPO внутри Android WebView через `server.url`. Это **только для раннего тестирования**, а не готовая публикационная сборка. Поэтому нужен интернет, сайт обновляется отдельно, а подтверждение почты, внешние ссылки, кнопка «Назад», выбор фото, сессии и разрешения потребуют тестирования и возможных доработок. Для выхода в Google Play потребуется убрать удалённый `server.url`, подготовить локальные web-ресурсы / совместимый мобильный клиент, обработать deep links и правила магазина, а также подписать выпускной APK/AAB.

Не запускай `npx cap sync` из корня Next.js-проекта: работай только в `mobile/android`.

Идентификатор Android сейчас `app.tempoarea.mobile` как предварительный; перед первой публичной публикацией его нужно окончательно согласовать.
