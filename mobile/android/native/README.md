# Кнопка «Назад» на Android

Для тестового приложения TEMPO добавлен Java-класс, который обрабатывает системную кнопку или жест «Назад»: переходит к предыдущей странице внутри WebView; если истории нет — закрывает приложение.

**Внешний вид сайта не изменяется.** Этот обработчик относится только к Android.

## Как применить на Windows

1. Обнови ветку `feature/android-capacitor` на компьютере (или скачай её ZIP заново).
2. В CMD из папки `C:\TEMPO-android\mobile\android` выполни:

```cmd
copy /Y native\MainActivity.java android\app\src\main\java\app\tempoarea\mobile\MainActivity.java
```

3. Затем собери APK через Android Studio (Build APK(s)) или через CMD из вложенной папки `android`:

```cmd
gradlew.bat assembleDebug
```

**Важно:** `npm install` и `npx cap sync android` сами по себе не копируют этот Java-класс. Папка Android генерируется локально и исключена из Git. Изменение заработает **только после копирования Java-файла и новой сборки APK**.

После теста проверь жест «Назад» на ленте, профиле и страницах входа. При возврате между экранами с внутренними модальными окнами возможны отдельные улучшения.

Пока используем удалённый HTTPS-сайт через `server.url`, работа приложения зависит от доступности сайта, иногда с VPN.
