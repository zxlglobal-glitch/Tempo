# Проверка Android-приложения TEMPO

Версия: тестовая оболочка Capacitor с удалённым HTTPS-сайтом.

## 1. Сохранение авторизации

1. Открой TEMPO на Android и войди в аккаунт.
2. Закрой приложение через список недавних приложений (смахни карточку).
3. Открой TEMPO снова. Аккаунт должен остаться активным.
4. Повтори после перезагрузки телефона.

Если авторизация сбрасывается, собери диагностические данные WebView и Supabase auth, прежде чем менять хранение токенов. Не публикуй ключи доступа и токены.

## 2. Фотографии

1. В профиле попробуй заменить аватар на JPG или PNG.
2. В новой тренировке выбери несколько фотографий, затем проверь превью и публикацию.
3. В сообщениях проверь прикрепление одного изображения.
4. Если галерея не открывается, проверь логи Android WebView и реализацию file chooser. Не добавляй опасные разрешения Android без необходимости.

## 3. Навигация

Проверь системную кнопку/жест назад на ленте, в профиле, сообщениях и модальных окнах. Текущий native-обработчик работает по WebView history, а не по Next.js router history; для client-side переходов может понадобиться дополнительное согласование.

## 4. Сеть

Проверь работу с VPN и без VPN. Приложение требует доступности Netlify и Supabase. Не путай недоступность сайта с проблемой APK. В будущей сборке нужен экран сетевой ошибки вместо чёрного экрана.

## Безопасность

Не отправляй пароль, session access_token, refresh_token или service_role key в скриншотах.

Никаких изменений в интерфейсе сайта для этой проверки не требуется. Netlify не запускать.
